# 문서가 `end` 라고 적혀 있었고, 서버는 `off` 만 봤다 — 끄기가 켜기가 됐다

- **날짜**: 2026-09-04 (사고는 09-03 실기기)
- **깨진 가정**: **"명세 문서를 믿고 클라이언트를 만들면 된다."**

## 무슨 일이 있었나

폰에 프라이빗 모드 타일을 붙이면서 `android/docs/private-mode.md` §3 을 그대로 따랐다.

```
| 토글 | `POST /ingest/private` — `{"minutes": 60}` 또는 `{"end": true}` |
```

타일로 껐는데 **꺼지지 않았다.** 젯슨은 `active: true` 를 돌려줬고, `until_ts` 는
누를 때마다 60분씩 뒤로 밀렸다. 끄려고 누른 것이 **켜기**였다.

## 왜

서버는 `off` 만 본다. 그리고 `else` 가 나머지를 **전부** 받는다.

```python
if body.get("off"):
    st = privacy.end_now(conn)
else:
    minutes = _parse_minutes(body, cfg.private.max_minutes)   # minutes 없으면 기본값 60
    st = privacy.begin(conn, minutes, source="tile", device=device)
```

`{"end": true}` 는 `off` 가 없으니 `else` 로 떨어지고, `_parse_minutes` 가 `minutes`
없음을 보고 `default_minutes` 를 쓴다. 게다가 `privacy.begin` 은 이미 켜져 있으면
`end_ts` 를 `max()` 로 **연장**한다 — 그래서 누를수록 길어졌다.

`{}` · `{"off": false}` · `{"minutse": 5}` 도 전부 같은 길로 간다. **오타 하나가
정반대 동작이 된다.**

## 가정이 깨진 지점

두 겹이다.

1. **문서와 코드가 갈렸는데 아무도 몰랐다.** 둘 다 09-01 커밋이다. 이 경로를 POST 하는
   코드가 저장소 안에 하나도 없어서(PC 헬퍼는 `GET` 만 한다) 문서가 틀렸다는 것을
   드러낼 것이 없었다. **첫 클라이언트가 폰이었고, 그게 밖에 있었다.**
2. **모르는 입력의 기본값이 "실행"이었다.** 못 알아들었으면 아무것도 안 하는 것이
   기본이어야 하는데, 여기서는 못 알아들은 것이 **켜기**였다.

`/api/private` 은 같은 병이 없다 — 켜기 `POST` · 끄기 `DELETE` 로 **동사**가 가른다.
모호함은 둘을 POST 하나에 몰아넣은 `/ingest/private` 에만 있었다.

## 고친 것

- `off` 와 `end` 를 **둘 다** 받는다. 문서가 `end` 로 나간 이상 그걸 보내는 것이 있다고 봐야 한다
- **모르는 본문은 400.** `minutes` 가 명시됐거나 본문이 완전히 빈 경우만 켠다
  (빈 본문은 모호한 것이 아니라 생략을 허용한 계약이라 그대로 뒀다)
- 문서의 `{"end": true}` → `{"off": true}`, 그리고 왜 바뀌었는지를 표 밑에 남겼다
- **테스트를 세 개 붙였다.** 이 경로에는 POST 하는 테스트가 **하나도 없었다** —
  그래서 계약이 뒤집혀 있어도 초록불이었다

## 남는 것

`/ingest/private` 이 여전히 POST 하나로 두 방향을 나른다. 동사로 가르는 편이 깨끗하지만
이미 나간 폰이 POST 를 쓰고 있어 지금은 본문으로 가른다.
