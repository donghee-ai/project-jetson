# 기기 보안을 **결정한 기록**이 없다 — 그래서 같은 검토를 반복한다

- **상태**: ⚫ **`n` — 하지 않기로 했다 (2026-09-07 사람이 판정).**
  사유: *"주기적 재부팅이라 넘어간다."*

> ★ **적어 둔 사유가 이 이슈의 내용과 딱 맞지는 않는다.** 여기 있는 것은
>   암호화·방화벽·유닛 하드닝을 *어떻게 하기로 했는지 적자*는 건이고,
>   주기적 재부팅은 메모리 누수(`h-0019`)를 눌러 두는 장치다.
>   그래도 판정은 사람의 몫이라 그대로 적는다 — **말을 바꿔 적으면 다음에
>   "왜 안 했지" 를 다시 묻게 된다.** 다시 볼 뜻이 생기면 이 줄부터 읽으면 된다.
  안 하기로 하는 것도 결정이고, 안 적으면 그 결정이 없는 것과 같다
- **발견**: 2026-08-28 정비 계획의 "사람이 정할 몫" 이 넉 달째 빈칸이었다
- **증상**: 아래가 전부 미결이고, 미결이라는 사실 말고는 아무것도 안 적혀 있다

  | | 지금 |
  |---|---|
  | 디스크 암호화 · Secure Boot | 판단 안 됨 |
  | 방화벽 기본 정책 (UFW/nftables) · SSH 키 전용 | 판단 안 됨 — Tailscale 이 죽었을 때 잠기는 위험과 같이 봐야 한다 |
  | avahi(5353) | `ubuntu.local` 이 필요한지 안 정함 |
  | 유닛 하드닝 (`NoNewPrivileges`·`PrivateTmp`·`ProtectSystem`·`ReadWritePaths`·`UMask`) | 안 붙임 |
  | Cloudflare 터널 공개 범위 | 지금 `/ingest/` 만 — 재확인 주기 없음 |

- **재현**

  ```bash
  ss -tulnp | grep LISTEN            # 열려 있는 것
  systemctl --user cat lifetrainer-web | grep -cE 'NoNewPrivileges|ProtectSystem'   # 0
  lsblk -f | grep -i crypt           # 없다
  ```

- **원인**: **"개인 장비라 안 해도 된다"는 판단은 옳을 수 있는데, 그 판단이 어디에도 없다.**
  근거 없는 미결은 다음 사람(그리고 다음 달의 나)에게 미검토와 구분되지 않는다.
  `rpcbind`·CUPS 는 같은 목록에서 **판정하고 닫았다** — 되는 방식은 이미 증명됐다.
- **영향**: 검토가 반복된다. 이 저장소가 `docs/archive/` 를 지우지 않는 이유와 같은 문제다 —
  *"왜 안 골랐는지가 남아 있지 않으면 같은 후보를 다시 검토한다."*
- **아직 모르는 것**: 위협 모델을 한 번도 안 적었다. 무엇으로부터 지키는지가 없으면
  각 항목의 값을 못 매긴다
- **고칠 것**
  - 한 문서에 **위협 모델 세 줄** + 항목별 **적용/미적용과 그 근거**를 적는다
  - 유닛 하드닝은 근거가 필요 없다 — 비용이 거의 0 이라 그냥 붙인다.
    단 `ReadWritePaths` 를 빠뜨리면 조용히 안 도므로 붙인 뒤 `make check` 와 재부팅으로 본다
