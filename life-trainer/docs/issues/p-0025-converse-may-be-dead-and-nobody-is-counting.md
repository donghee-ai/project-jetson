# `converse` 가 죽었는지 산 건지 세는 것이 없다

- **상태**: `p-` — 지우자는 것이 아니라 **결정할 재료를 모으자**는 것이다
- **발견**: 2026-08-24 에 에이전트가 자연어의 기본 경로가 되면서 열렸다.
  2026-08-28 정비 계획이 *"2~3주 뒤 실사용 빈도 보고 결정"* 으로 적어 뒀다
- **증상**: `llm/converse.py` 경로는 에이전트가 기본이 된 뒤 **폴백으로만** 남았다.
  그런데 **폴백이 몇 번 탔는지 세는 곳이 없다.** 세는 것이 없으니 2~3주가 지나도
  결정할 재료가 안 쌓인다.
- **재현**

  ```bash
  git grep -n 'converse' -- '*.py' | grep -iE 'warn|fallback'   # 없다
  ```

- **원인**: "나중에 빈도를 보고 정한다"고 적었는데 **빈도를 남기는 코드를 안 넣었다.**
  기한만 있고 계측이 없는 결정은 기한이 와도 못 내린다.
- **영향**: 두 경로를 계속 유지한다. `converse` 는 툴 스키마·프롬프트를 따로 갖고 있어
  에이전트 쪽을 고칠 때마다 같이 봐야 한다.
- **아직 모르는 것**: 지금 폴백이 실제로 타는지조차 모른다. 0 일 수도 있다
- **고칠 것**
  - 폴백을 탈 때 **로그 한 줄**을 남긴다 (경고 아님 — 정상 동작이다)
  - 2~3주 뒤 `journalctl` 로 세어 보고 **0 이면 지운다.** 0 이 아니면 왜 타는지가 다음 질문이다
  - 지울 때는 [`n-`](README.md) 이 아니라 **삭제 커밋**이다. 안 쓰는 경로를 남겨 두면
    다음 사람이 그것도 유지해야 한다고 읽는다
