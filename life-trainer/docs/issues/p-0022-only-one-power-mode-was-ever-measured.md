# 전력모드를 하나만 재 봤다 — 15W · 25W 는 빈칸이다

- **상태**: `p-` — 기기는 MAXN 으로 돌고 있고 당장 바꿀 이유가 없다.
  다만 **루트 README 가 스스로 빈 그림을 인정하고 있다.**
- **발견**: 2026-08-28 정비 계획 리뷰. 2026-08-31 이관 시 `measure/results/` 를 다시 확인했다
- **증상**: 측정은 전부 MAXN 에서 났다. [`README.md`](../../../README.md) ①이
  *"성능 수치가 안 붙어서 그림을 안 그린다"* 고 적어 뒀는데, 그 빈칸이 이것이다.
- **재현**

  ```bash
  sudo nvpmodel -q                       # 지금 MAXN
  ls measure/results/ | grep -iE '15w|25w'       # 없다
  ```

- **원인**: 모드를 바꾸면 다른 측정을 전부 다시 해야 한다고 보고 미뤘다.
  그런데 필요한 것은 전체 재측정이 아니라 **같은 축의 한 점 하나**다.
- **영향**: 와트당 성능을 말할 수 없다. 저전력 배치 가능성도 판단 못 한다.
- **아직 모르는 것**: 15W 에서 8B 가 뜨는지조차 안 재 봤다 (메모리는 되지만 속도는 미지수)
- **고칠 것**
  - **15W 1회 측정** — 이 한 번이 README ①의 빈 그림과 전력모드별 와트당 성능을 같이 푼다
  - 루트 [`README.md`](../../../README.md) 에 **"1회 측정"** 을 명시한다.
    [`measure/README.md`](../../../measure/README.md) 는 이미 적고 있는데 루트에는 없다
  - 모드를 바꾸면 [`p-0021`](p-0021-nothing-has-measured-this-machine-under-sustained-load.md)
    의 열 시험도 그 모드에서 한 번 돌린다 — 같이 하면 한 번에 끝난다
