# 문서 6,039건을 모아 두고 훑을 화면이 없다

- **번호**: `0015`
- **발견일**: 2026-08-23 · **재측정 2026-08-27 (4,315 → 6,039건)**
- **상태**: 🔵 **p — 기능 공백.** 결함은 아니지만 **판단을 막는다**

## 증상

```
수집한 문서        6,039건
lt digest         상위 5건만
Slack             검색만
웹                문서 라우트 0개
```

**모아만 두고 볼 방법이 없다.** 그래서 *"이 문서들을 계속 모을 값이 있나"* 를
판단할 수 없다 — 원래 기록도 *"지울지 정하려면 이게 먼저다"* 라고 적었다.

## 왜 `p` 인가

동작이 깨지지 않고, 우회로가 있다(`lt digest`·Slack 검색·SQL 직접 조회).
다만 **다른 결정들이 이것을 기다리고 있다** — 관심사 확대(HANDOFF §7-C),
청킹 전략([`0004`](../../HISTORY/2026-09-03-the-template-kept-falling-behind-the-code.md) 의 `batch_size`),
문서 보존 기간이 전부 "무엇이 쌓였는지 봐야" 정할 수 있다.

## 고칠 것

웹에 문서 라우트 하나. 플래너가 이미 인증·템플릿·정적 자산을 갖고 있으므로
목록 + 필터(점수·날짜·요약 유무) 한 화면이면 된다.
