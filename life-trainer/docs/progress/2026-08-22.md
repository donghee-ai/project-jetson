## 구조 변경 — 마이그레이션 003

`slot_breakdown` 의 기본키에 `device_id` 를 넣었다.
**컬럼은 002 가 만들어 뒀는데 기본키가 옛날 그대로라, 채우는 순간 PK 충돌로 터지는

SQLite 는 PK 를 ALTER 로 못 바꾸므로 테이블을 다시 만든다. `slot_breakdown` 은
`aw_event` 에서 무손실 재생성되는 파생 데이터라 옮기지 않고 비웠고(002 와 같은 선택),
`lt rollup --range 2026-08-12 2026-08-23` 으로 12일치를 다시 채웠다 — **2.7초**.

## 밤에 이어서 — 폰 시간이 통째로 '자리비움'이었다

카드는 붙었는데 격자에는 폰이 안 보였다. 실측:

폰 window 이벤트를 `not-afk`·`afk`·보고 공백으로 나누자, 보고 공백 구간이 전부
`away`로 떨어지고 있었다. 한 게임 세션도 통째로 자리비움이 됐다. 개별 앱 이름과
사용 시각·분량은 공개본에서 제거했다.
그 구간에 폰의 afk 버킷은 **afk 도 not-afk 도 아무 이벤트가 없었다.**

### 깨진 가정 — "not-afk 로 안 덮인 시간은 자리비움이다"

폰의 afk 워처는 **살아 있어야 보고한다** — Doze 에 들어가면 통째로 멈춘다. 반면 앱
세션(UsageStats)은 시스템이 **소급해서** 기록하므로 Doze 구간도 나중에 그대로 올라온다.
즉 보고 공백 구간에서는 앱 세션이 **더 나은 증거**다.

두 구간의 성격이 실제로 달랐다:

| | 이벤트 | 시간 | 앱 종수 | 평균 |
|---|---|---|---|---|
| 명시적 afk 구간 | 드문 앱 전환 | 긴 평균 구간 |
| **보고 공백 구간** | 잦은 앱 전환 | 짧은 평균 구간 |

공백 구간이 촘촘한 앱 전환이다 — 손이 닿은 모양이다.
→ `_activity_intervals` 이 **명시적 `afk` 는 그대로 존중하고, 보고가 없는 구간의 앱
세션만** 활동으로 인정한다. 결과는 합성 회귀 데이터로 검증한다.

퍼블리셔 접두사만으로 잡히지 않는 인디/이식작 규칙도 `rules.yaml`에 추가했다.

## 플래너를 인터넷에 열었다 — `lt.example.com/planner`

### 먼저 드러난 것: 플래너에 인증이 없었다

`_enforce_auth` 가 **`cfg.web.external` 일 때만** 세션을 요구했다. 그 값이 false 라
tailnet 에서 인증 없이 열리는 게 정상이었는데, **터널만 열고 이 플래그를 깜빡하면
플래너가 통째로 공개되는 구조**였다. 실제로 `curl http://…:8770/d/2026-08-22` 가 200 이었다.

플래그 하나가 인증·Secure 쿠키·마스킹 세 가지를 한꺼번에 켜는 것도 문제였다.
셋은 서로 다른 질문인데 묶여 있어서, 켜면 tailnet 에서 창 제목이 사라지고
tailnet 이 http 라서 Secure 쿠키는 저장조차 안 됐다.

### 요청 단위로 갈랐다

| 질문 | 이제 무엇으로 정하나 |
|---|---|
| 세션을 요구할까 | 요청 **호스트**가 `web.external_host` 면 무조건 요구 (플래그와 무관) |
| Secure 쿠키를 걸까 | 그 요청이 **HTTPS 였나** (`X-Forwarded-Proto`) |
| 제목을 지울까 | 외부 요청이고 `web.external_mask` 가 켜져 있을 때만 |

같은 프로세스가 터널(HTTPS·인증)과 tailnet(HTTP·직결)을 동시에 서빙하므로
설정 하나로는 어느 쪽이든 깨진다.

### `/planner` 접두사

앱을 접두사 아래에도 응답하게 했다(`web.url_prefix`, WSGI 미들웨어).
**터널과 Access 를 경로 하나로 막기 위한 것이다** — `/d/` `/api/` 를 하나씩 열거하면
나중에 라우트를 추가하면서 목록 갱신을 잊는 순간 조용히 노출된다. 경계는 한 줄이어야 한다.
tailnet 직결은 접두사 없는 예전 주소도 그대로 받는다(북마크·기존 링크 보존).

### 실제 인터넷 경로로 확인

```
https://lt.example.com/planner/d/2026-08-22        → 401
https://lt.example.com/planner/api/day/2026-08-22  → 401   (본문에 데이터 없음)
https://lt.example.com/d/2026-08-22                → 404   (터널이 차단)
https://lt.example.com/healthz                     → 404
서명 링크 → 302 → 쿠키(HttpOnly·Secure) → 200
```

Slack 카드 링크(`web.base_url`)도 이 주소로 바꿨다 — tailnet 밖(폰 LTE)에서 열린다.

### 남은 한 겹 — Cloudflare Access

지금 문지기는 **앱의 서명 링크 세션 하나**다. Access 를 앞에 세우면 인증되지 않은
요청이 젯슨에 닿기 전에 Cloudflare 에서 끊긴다. 대시보드 로그인이 필요해 사람이 해야 한다.
`/ingest/` 는 반드시 **우회**시켜야 한다 — 폰에는 브라우저 세션이 없다.

## 대화가 계획 시간대에 막혀 있었다

**"심심해" → "지금은 문서 정리 시간입니다."** 계획 시간대에는 무슨 말을 걸어도 계획을 읊었다.

원인은 프롬프트 조립이었다. 배경이 **사용자 메시지 안에** 이어 붙어 있었다:

```
(현재 2026-08-22 21:10, 논리적 하루 2026-08-22)
지금 시간대 계획: 문서 정리 (20:00~22:00, 50분 남음)
[오늘 실제 활동 — 기계 측정] 카테고리별 합계…
심심해                                    ← 사용자가 실제로 한 말
```

8B 입장에서 "심심해"는 마지막 한 줄이고 앞의 세 줄이 더 크게 보인다.

### 세 겹으로 고쳤다

1. **배경과 질문을 라벨로 가른다** — `[배경 — 참고용]` / `[사용자의 말]`
2. **계획을 묻지 않은 턴에는 그 줄을 아예 안 싣는다** — 프롬프트에 "먼저 꺼내지 마라"를
   넣어도 줄어들 뿐 안 없어졌다. 못 걸러도 안전한 이유: 조회 툴(`get_plans`)은 항상 실린다.
   주입은 툴 한 바퀴를 아끼는 최적화지 유일한 경로가 아니다
3. **직전 답을 반복하면 다시 생성한다** — 되묻기("그래서 대답 못한다고?")에 직전 답을
   그대로 복사했다. 생성 뒤 `SequenceMatcher` 로 보고, 걸리면 system 지시 + 온도 0.8 로
   **한 번** 다시 생성한다. 그래도 같으면 **중복을 내보내지 않고** 되묻기 안내로 대체한다

### 곁들여 잡은 것 — "지금 뭐 해야 해?" 가 웹 검색으로 샜다

`(지금).{0,8}(뭐)` 패턴에 걸려 바깥 조회로 가서 엉뚱한 reddit 글을 물어왔다.
**자기가 할 일**을 묻는 말이라 계획 질문이다 — `(뭐|무엇|뭘)\s*(해야|하지|할까)` 를
개인 패턴에 넣어 뺐다. `지금 뭐가 유행이야?` 는 그대로 웹으로 간다.

### 검증 (실제 모델로 5턴)

```
심심해              → 지금은 집중할 일이 없으시군요. 즐거운 시간 보내세요!
그래서 대답 못한다고?  → (다른 문장으로 답한다)
왜 자꾸 같은 말 해?   → 같은 답을 반복하고 있습니다. 조금만 더 구체적으로…
지금 뭐 해야 해?     → 문서 정리에 50분 남았으니, 지금 바로 시작하면 좋겠어요
오늘 코딩 얼마나 했어? → 오늘 코딩 시간을 집계해 답함
```
