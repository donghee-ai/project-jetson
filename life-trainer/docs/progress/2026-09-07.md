
전에는 삭제 직후 잠깐 뜨는 토스트뿐이었다 — **새로 고치면 되돌릴 길이 사라졌다.**

## (6차) CI 가 알려 준 것 — 3.10 을 걷어내고 고정본을 다시 뽑았다

푸시하고 **CI 가 이틀 만에 처음 돌았다.** 두 가지가 나왔다.

### ① py3.10 잡이 실패했다 — 내가 쓴 테스트가

```
FAILED tests/test_config.py::test_example_toml_의_값이_코드_기본값과_같다
       ModuleNotFoundError: No module named 'tomllib'
```

전날 백포트를 조건 없이 부르지 말라는 검사를 만들어 놓고,
**바로 그 파일에 `import tomllib` 을 조건 없이 썼다.** 로컬은 전부 3.14 라 안 보였다.

확인해 보니 **앱은 3.10 을 전혀 안 쓴다** — 서비스 셋도 타이머도 전부 `.venv`(3.14)다.
즉 `>=3.10` 은 *아무도 안 쓰고 검사도 안 되던 약속*이었고, 그걸 지키느라
**빨간불이 상수가 될 뻔했다.**

| | 전 | 후 |
