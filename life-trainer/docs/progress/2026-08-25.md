활동 인정과 소유권을 갈랐다 — `TOUCHED`(afk 가 말한 것)가 `PRESENT`(공백을 세션으로

## 계획 보기를 되돌렸다 — 덮어쓰기가 아니라 겹쳐 그리기

같은 날 오후에 다시 나왔다. 처음 만든 계획 ON 은 `.grid.show-plan .cell` 로
**격자 전체**를 계획 색으로 칠하고, 계획 없는 칸에는 빈칸 색을 실어 보냈다.
"하루를 계획표 한 장으로 읽는다"는 뜻이었는데, 실제로 쓰면 **계획이 세 시간뿐인
날은 나머지 스물한 시간의 측정 결과가 통째로 사라진다.**

원하는 것은 그게 아니었다 — **계획이 걸린 시간만 덮고 나머지는 손대지 않는다.**

고친 곳은 두 군데뿐이다.

| | |
|---|---|
| `web/app.py` | 계획 없는 칸의 `--plan-color` 를 `--structural-off` → `--cell-color` (자기 활동 색을 되돌려준다) |
| `planner.css` | `show-plan` 규칙 7개를 전부 `.cell` → `.cell.has-plan` 으로 좁혔다 |

토글 자체는 안 건드렸다(클래스 하나를 붙였다 뗀다). 실기기 확인:

```
OFF      계획 칸 배경 6색(측정) · 무계획 칸 3색
ON       계획 칸 배경 1색(--cat-coding, 계획) · 무계획 칸 3색 그대로  ← 안 변한다
다시 OFF 원래대로 복귀
```

회귀 테스트 `test_plan_view_leaves_unplanned_time_untouched` 가 두 가지를 못박는다:
응답에 `--plan-color: var(--structural-off)` 가 없을 것, 그리고 CSS 에
`.has-plan` 없는 `show-plan` 선택자가 하나도 없을 것(정규식으로 센다).

## 죽은 분기 하나를 지웠다 — 네이버 검색

리뷰에서 나왔다. `_pick_provider` 가 **한국어면 네이버를 먼저 고르고 있었다.**
키가 비어 있어서 Serper 로 폴백했을 뿐이라, 누가 `naver_client_id` 를 채우면
한국어 질의만 은퇴한 엔드포인트로 가서 401 이 난다 — 영어는 멀쩡해서 "검색이
고장났다"로도 안 보인다.

Serper 단독은 2026-08-21 에 이미 결정된 사항이었다. **결정이 끝난 분기를 코드에
남겨 둔 것이 함정이었다.** `NAVER_ENDPOINT`·`_naver`·`_clean`·`_pick_provider`,
설정 키 두 개, doctor 분기 둘, example.toml 안내를 지웠다.

`is_korean` 은 남겼다 — 공급자를 고르던 자리에서 `gl=kr&hl=ko` 를 붙일지 정하는
자리로 옮겨 앉았다. 한국어 질의는 여전히 한국 구글로 간다.

`docs/known-issues.md §4` 를 해결로 닫았다.
