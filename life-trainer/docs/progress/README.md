# 진행 기록

**날짜별 진행사항.** 큰 기능이 추가되면 여기에 쓴다.
버그 수정은 [../../HISTORY/](../../HISTORY/) 로 간다.

## 규칙

- 파일명: `YYYY-MM-DD.md`. 하루에 여러 번 작업해도 파일은 하나
- 사소한 수정·리팩터는 쓰지 않는다. **기능이 늘거나 구조가 바뀐 것**만
- 버그 수정은 여기 쓰지 말고 HISTORY 에. 다만 그날 요약에서 링크는 걸어준다
- 다음을 채운다:

```markdown
# YYYY-MM-DD

## 한 줄
## 추가된 기능
## 구조 변경 (있으면)
## 검증 (테스트 수, 실측 숫자)
## 남은 것
```
