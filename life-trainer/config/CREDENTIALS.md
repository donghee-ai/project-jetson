# 자격증명 교체 이력 — **값은 절대 적지 않는다**

`config/lifetrainer.toml` 은 `.gitignore` 대상이라 **자격증명을 갈아도 git 에 흔적이
남지 않는다.** 2026-08-31 에 그 대가를 치렀다 — Serper 키를 08-28 에 갈아 놓고
기록이 없어서, 일주일 뒤에 [08-25 사고 기록](../HISTORY/2026-08-25-the-gitignore-net-had-a-suffix-shaped-hole.md)
을 읽고 **이미 한 일을 다시 제안했다.**

## 규칙

- **값·앞자리·길이를 적지 않는다.** 이 파일은 추적되므로 여기 적으면 그게 유출이다
- 식별이 필요하면 **sha256 앞 12자**만 쓴다 (역산 불가, 대조는 가능)
- 적는 것은 **언제 · 무엇을 · 왜** 셋뿐이다
- 대조하는 법:
  ```bash
  grep -oE 'serper_api_key *= *"[^"]+"' config/lifetrainer.toml \
    | grep -oE '"[^"]+"' | tr -d '"' | tr -d '\n' | sha256sum | cut -c1-12
  ```

## 이력

| 날짜 | 무엇 | sha256(앞12) | 왜 |
|---|---|---|---|
| ~2026-08-21 | Serper API 키 (최초) | `0e7343926bcd` | 검색 계층 가동 |
| 2026-08-28 | Serper API 키 (교체) | `a7d9ebdde911` | `.bak` 파일 4개가 커밋돼 옛 키가 이력에 남았다 (08-25 사고). **옛 키는 Serper 에서 삭제 확인 (2026-08-31)** |

## 아직 안 적힌 것

Slack 봇·앱 토큰, 웹 세션 시크릿, 폰 ingest 시크릿, Tailscale·Cloudflare 자격증명은
**교체한 적이 없어서** 줄이 없다. 갈면 여기 한 줄 추가한다.
