# android/ — 폰 사용 기록 수집

**상태: 가동 중.** 포크가 2026-08-22 에 붙었고 폰이 5분마다 밀어 넣는다.
**앱 코드는 이 폴더가 아니라 별 저장소** [`donghee-ai/lt-phone`](https://github.com/donghee-ai/lt-phone)
에 있다 — 여기 있는 것은 설계·조사·운영 문서다.

개인 사용 습관을 드러내므로 공개본에는 싣지 않는다.

### ★ 2026-08-21 에 바뀐 결론

**"포크가 필요한지 실물 보고 정하자" → 실물이 "필요하다"고 답했다.**

공개 APK(`v0.14.0dev20260723`)로 표본을 뽑는 경로가 **양쪽 다 막혔다** —
REST 는 API 키를 요구하는데 **키 설정 화면이 master 에만 있고 APK 에는 없고**,
앱 내 Export 는 `blob:` 다운로드를 처리 못 해 **크래시한다**(업스트림 이슈 #228 악화).

그런데 그 지름길은 원래 이 판단을 위한 것이었고, **상시 자동 전송은 어차피 포크
없이는 성립하지 않는다.** 자세한 것은 [docs/runbook.md](docs/runbook.md) §③·§⑥.

젯슨 쪽은 **폰 없이 만들 수 있어서 먼저 끝냈다.** 자세한 것은
[08-19 진행 기록](../docs/progress/2026-08-19.md).

- ★★ [docs/phone-titles.md](docs/phone-titles.md) — **폰에서 무엇을 했는지: 제목을 채우는 길 (F4·F5).**
  재생 중인 것은 45% 붙고 웹 페이지 제목은 0% 다. 실측과 고칠 지점.
- ★★ [docs/private-mode.md](docs/private-mode.md) — **프라이빗 모드 폰 명세 (타일·커서 건너뛰기).**
  젯슨 쪽은 이미 들어가 있다. 먼저 Secure Folder 로 되는지 5분만 재 볼 것
- ★★ [docs/fork-build.md](docs/fork-build.md) — **포크 빌드 지시서 (Windows PC).**
  **이 문서 하나만 들고 다른 세션에서 시작할 수 있게** 썼고, 실제로 그렇게 지어졌다.
  HMAC 규격(`LT1`)·버킷 표·판별 순서가 여기 있다 — 워처를 더 붙일 때 먼저 읽는다
- [docs/runbook.md](docs/runbook.md) — 전체 실행 순서 (폰 설정·게이트·Cloudflare)

## 왜 코드가 없는데 폴더가 있나

조사 결과를 대화 밖에 남겨두지 않기 위해서다. 이 프로젝트에서 반복된 실패 1번이
"조사 문서를 사실로 믿었다" 인데, 그 반대편 실패는 **조사한 것을 안 적어서 다시
조사하는 것**이다. 확인한 것과 확인 못 한 것을 구분해서 남긴다.
