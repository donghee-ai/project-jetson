## 기록 규칙 (반드시 지킬 것)

| 무엇 | 어디에 |
|---|---|
| **큰 기능 추가 · 구조 변경** | `docs/progress/YYYY-MM-DD.md` (하루 한 파일, 색인 갱신) |

각 폴더의 `README.md` 에 양식이 있다. **버그는 고친 코드가 아니라 깨진 가정을 쓴다.**

## 이 프로젝트에서 반복된 실패 (같은 부류를 의심할 것)

1. **조사 문서를 사실로 믿었다** — 문서는 "그 구현"에 대한 사실이지 "그 제품"이 아니다.
   붙일 대상의 실물(버전·구현체)을 확인하라
2. **같은 값을 여러 곳에서 각자 계산했다** — 파생값은 한 곳에서만 계산하고 나머지는 받아 쓴다
3. **계산 가능한 것을 눈대중으로 정했다** — 색각 분리는 검증기로 계산한다
4. **테스트 통과 ≠ 동작** — 산출물(PNG·HTML)을 실제로 열어봐라

## 하드웨어가 강제하는 규칙

- **JSON 스키마에 `pattern` 금지** — llama.cpp GBNF 변환기가 요청 전체를 400 으로 거부.
  **툴 스키마도 마찬가지다** (OpenClaw 의 `cron` 툴이 정확히 이걸로 죽었다)
- **JSON 출력·툴 콜링 시 thinking off** — 사고 텍스트가 섞여 파싱이 깨진다
- **LLM 입력 3~5K 로 끊기** — 깊이 32K 에서 생성 속도 −70%
- **파이썬 상주 300MB 이하** — 가용 메모리 2.8GB (llama-server 가 10.4GB 사용 중)
- **GPU 잡 동시 실행 금지** — `fcntl.flock`
- **모델 id 까지 확인** — 포트만 보는 헬스체크가 1시간 무중단 다운을 낸 적 있다

## 기본값

- 논리적 하루 = **KST 06:00 → 다음날 06:00**, `slot 0 = 06:00~06:10`
- 집계 원천은 `slot_breakdown` (`slot` 의 winner-takes-all 은 시각화 전용)
- **5분 미만 기기 전환은 앞 활동으로 흡수한다** (`rollup.absorb_short_switches`).
  "코딩 10분 → 폰 3분 → 코딩 10분" 은 코딩 23분이다 — 잠깐 딴짓까지 다 찍히면
  플래너를 읽을 수 없다. 임계값은 `rollup.switch_absorb_sec`
- 색은 `config/palette.yaml` 단일 원본. 하드코딩 금지
- **Slack 발송은 `--post` 등 명시적 지시가 있을 때만**

## 대화 프롬프트 규칙 (`llm/context.py`·`converse.py`)

- **3층을 지킨다. 변하는 주기가 짧은 것일수록 뒤에.** llama.cpp 가 공통 접두사를
  앞에서부터 재사용한다 — 현재 시각·실측 활동을 시스템에 넣으면 하루 종일 캐시가 깨진다

  ```
  ① 시스템   역할 + 오늘 계획(의도) + 관심사    하루 단위    165 토큰
  ② 툴       트리거가 고른 것만                턴마다       271~595
  ③ user     현재 시각 + 실측 활동 + 질문       매 턴        ~35
  ```

- **의도(`plan_instance`)와 측정(`slot`)을 프롬프트에서도 함께 싣는다.** 한쪽만 실으면
  모델이 그걸로 나머지를 지어낸다 ([실제 사고](HISTORY/2026-08-17-plan-only-injection-hallucination.md))
- **항상 필요한 정보는 툴이 아니라 주입.** 소형 모델은 툴을 안 부르고 "확인했습니다"로
  끝내며 그때 에러가 안 난다
- **시스템 프롬프트에 문장을 더할 때는 몇 초짜리인지 먼저 계산한다.** 프롬프트 처리
  295 tok/s — OpenClaw 의 12,541 토큰이 곧 첫 턴 58초였다
- **모델에게 산술을 시키지 않는다.** 주어진 숫자를 인용만 하게 한다 (8B 가 달성률을 지어냈다)
- **툴 결과는 "무엇인지"와 "무엇이 없는지"를 같이 말한다.** 빈손일 때 다른 걸로
  대체하거나, 출처를 안 밝히면 모델이 그걸 사실로 취급한다 (실제 사고 2건:
  `HISTORY/2026-08-18-search-fallback-noise.md`)
- **바깥 정보를 묻는 턴은 `tool_choice="required"`.** `auto` 면 기억으로 지어낸다
